# HyperDrive backend

NestJS 11 + Mongoose + viem. It signs EIP-712 quotes for `HyperdriveDesk`, indexes the desk's `Trade` events into MongoDB, and serves portfolio, PnL and history data. See the [top-level README](../README.md) for the end-to-end flow and quickstarts.

```bash
npm install
npm run start:dev      # http://localhost:3001/api
npm test               # jest (src/portfolio/pnl.spec.ts)
npm run build && npm run start:prod
```

Requires MongoDB (default `mongodb://localhost:27017/hyperdrive`).

## Layout

```
src/config/configuration.ts   env → AppConfig (validates DESK_ADDRESS, QUOTE_SIGNER_PRIVATE_KEY)
src/chain/chain.service.ts    viem clients, desk reads (listing, feeBps, usdc), quote signer account
src/chain/desk-abi.ts         generated by contracts `npm run export-abi`; do not edit
src/market/catalog.service.ts xStock catalog from CATALOG_PATH
src/market/prices.service.ts  xStocks price-data API (live for quotes; 30s cache for marking)
src/quotes/                   POST /api/quotes
src/portfolio/trades.service.ts    decodes Trade logs, idempotent upsert, marks quotes filled
src/portfolio/indexer.service.ts   getLogs poller, cursor in indexer_state
src/portfolio/pnl.ts               average-cost ledger (bigint)
src/portfolio/portfolio.service.ts positions / PnL
src/portfolio/snapshot.service.ts  periodic portfolio value snapshots
src/health/                   GET /api/health, /api/desk
src/db/schemas.ts             Mongo schemas
```

## API (global prefix `/api`)

**`GET /health`**: `{status, mongo, chainId, desk, quoteSigner, indexer: {lastBlock, lag, ...}}`.

**`GET /desk`**: `{configured, chainId, desk, usdc, feeBps}`, or `{configured: false, chainId}` when no desk is set.

**`POST /quotes`**

```json
{ "trader": "0x…", "symbol": "AAPLx", "side": "buy", "amount": "100" }
```

`amount` is in human units: USDC for a buy, shares for a sell. Validation runs in this order:

1. The symbol is in the catalog and not halted.
2. The token is listed on the desk.
3. A live price is available.
4. The notional is within the min/max limits.
5. The trader's balance covers the amount.
6. Desk inventory covers the output (USDC gross for sells).

The response contains `desk`, `usdc`, `chainId`, `symbol`, `quote` (the struct to pass on-chain, with bigints as strings), `signature`, `expectedOut` (base units; pass it as `minSharesOut`/`minUsdcOut`), `expectedOutDecimal`, `fee`, `feeUsd`, `feeBps`, `marketPriceUsd`, `priceUsd` and `expiresAt`. Errors: `400` for bad input or limits, `409` for halted, unlisted or insufficient balance/inventory, `503` when there is no desk, no signer or no live price.

**`GET /portfolio/:wallet[?onchain=1]`**: positions (shares, cost basis, market value, realized/unrealized/total PnL and %, allocation, fees) and totals. `onchain=1` adds `onchainShares` read from the wallet.

**`GET /portfolio/:wallet/trades[?limit=100]`**: newest first, 1–500.

**`GET /portfolio/:wallet/history[?days=30]`**: snapshots from the last N days (1–365).

**`POST /trades/sync`** `{ "txHash": "0x…" }`: decodes that transaction's desk `Trade` logs now, upserts them, marks their quotes `filled`, and snapshots the affected wallets. Returns `{trades}`. It is idempotent with the poller.

## Collections

| Collection | Key / indexes | Notes |
|---|---|---|
| `trades` | unique `(chainId, txHash, logIndex)`; `(trader, timestamp)` | Source of truth. Amounts are stored as base-unit strings (`usdcAmount`, `shares`, `price`, `fee`) plus float display copies |
| `quotes` | unique `nonce`; `trader` | Each signed quote with market price, spread, expectedOut and signature. `status: issued → filled`, `txHash` |
| `indexer_state` | unique `key = trades:<chainId>:<desk>` | `lastBlock` fully stored. Restarts resume from here |
| `portfolio_snapshots` | `(wallet, at)` | `marketValue, costBasis, realizedPnl, unrealizedPnl, netInvested` |

## PnL

The ledger is average cost per token, computed in bigint over trades in `(block, logIndex)` order. Buys add the USDC paid (fee included) to the cost basis. Sells realize net proceeds minus `cost * sold / held`. Shares sold beyond the desk-recorded position (tokens received from outside the desk) have zero basis, and holdings are clamped at 0. Unrealized PnL marks the position at the live xStocks price, or at the last trade price when the API has none. The `pnl.spec.ts` tests cover these rules.

## Notes

- The quote signer key is hot. Keep it dedicated and unfunded. Rotating it takes `setQuoteSigner` on the desk plus an env change.
- The xStocks price-data API is indicative, not executable. Size `QUOTE_SPREAD_BPS` and `QUOTE_TTL_SECONDS` to fit.
- After a desk ABI change, run `npm run export-abi` in `contracts/` to regenerate `src/chain/desk-abi.ts`.
